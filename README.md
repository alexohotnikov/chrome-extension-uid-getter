# ![icon](/icons/icon_white.png) Chrome Extension UID Getter

A Chrome extension that helps you quickly copy UID from cookies and access student credentials with a single click.

![Extension Preview](/preview-images/v5.png)

## Features

- One-click UID copying from cookies
- Quick access to student credentials
- Automatic copying of credentials to clipboard
- Visual feedback for successful operations
- Error handling and retry functionality

## Installation

1. Open Chrome and navigate to [Chrome Extension Page](chrome://extensions/)
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select the extension directory

## Usage

1. Click the extension icon in your Chrome toolbar
2. The popup will display:
   - Student ID (clickable link to admin panel)
   - Student credentials (click to copy)
   - UID copy button
3. Click any of the elements to copy the respective information to your clipboard
